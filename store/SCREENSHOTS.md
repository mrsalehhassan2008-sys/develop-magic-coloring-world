# 📸 Screenshots Guide

Google Play needs **2–8 screenshots** per form factor. Capture from the LIVE deployed app.

## Requirements
- Phone: 16:9 or 9:16, min 320px, max 3840px. Recommended **1080 × 1920** (portrait).
- 7-inch & 10-inch tablet: recommended **1200 × 1920** / **1600 × 2560**.
- PNG or JPEG, no alpha, no rounded corners added by you.

## How to capture (fast, free)
1. Open the deployed site in Chrome desktop.
2. DevTools (F12) → Toggle device toolbar → choose "Pixel 7" (phone) / "iPad" (tablet).
3. DevTools menu (⋮) → **Capture screenshot**.

## Recommended 8 shots (in this order — the first 2 matter most)
1. Home screen with the game tiles + buddy + stars/coins.
2. Coloring studio mid-color with the progress bar + a bright animal.
3. A finished big scene (garden / house by the sea) — shows depth of content.
4. Color-by-Numbers mode with the number legend visible.
5. Balloon Pop gameplay (particles + score).
6. The talking buddy speech bubble greeting the child by name.
7. Trophies / rewards screen.
8. Parent Area showing controls (builds trust with parents).

## Tip
Add a short caption band with the app's pastel colors above each screenshot in any image
editor (e.g. "120+ original pictures", "Learn while you play", "Safe & ad-free") — captioned
screenshots convert far better and help reach 4.8★+.
