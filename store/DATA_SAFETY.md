# Google Play — Data Safety Form Answers

Fill these exact answers in **Play Console → App content → Data safety**.

## Does your app collect or share any of the required user data types?
**Answer:** Yes (minimal). Choose the items below; everything else = **No**.

### Data collected
| Data type | Collected? | Shared? | Purpose | Optional? | Ephemeral? |
|-----------|-----------|---------|---------|-----------|------------|
| Name (nickname only, not real name) | Yes | No | App functionality (personalisation) | Yes | No |
| Photos (child's own artwork saved to gallery) | Yes | No | App functionality | Yes | No |
| App activity — in-app actions (high scores) | Yes | No | App functionality | Yes | No |

> Everything else — location, contacts, financial info, real name, email, phone,
> device IDs, advertising IDs, health, messages, browsing history — **NOT collected, NOT shared.**

## Security practices
- Data is encrypted in transit (HTTPS): **Yes**
- Users can request data deletion: **Yes** (Parent Area → Reset progress / Delete artwork)
- Committed to Play Families Policy: **Yes**

## Other required declarations
- Is all collected data processed ephemerally? Partly (artwork/scores stored until deleted).
- Do you collect data from children? The app is **designed for children**; only a nickname +
  their own artwork are stored, with a parental gate on all controls. No identifiers.
